01 — Overview

What is Shuddhi QA?

Transform plain-English requirements into production-ready test suites. No manual writing. No templates to fill. Just describe what needs to be tested.

⚡

Instant Generation

Generate 10–20 test cases in 10–30 seconds. Streams in real-time with quality scores for each test case.

🏢

Enterprise-Grade

Push to Azure DevOps Test Plans or export Jira Zephyr CSV. No copy-paste required.

🔒

Privacy First

API keys stay in your browser. Requirements never stored. Sign-in is optional. No advertising.

02 — Quick Start

Generate test cases in 4 steps

No account or API key required to start. Free for the first 3 generations.

1

Open the App

Go to shuddhiqacloud.vercel.app in any browser. No installation needed.

2

Select Platform

Click a platform chip — D365, Salesforce, Web App, etc.

3

Describe Requirement

Paste a user story, BRD, or process description. Up to 6,000 characters.

4

Generate

Press Generate (or Ctrl+Enter). Test cases stream in real-time.

💡
No API key needed. The app uses a shared server-side Groq key for free generations. Add your own key in Settings for unlimited usage.

06 — Integrations

Azure DevOps & Jira

Azure DevOps Push

StepAction
1. Get PATADO → User Settings → PAT → Test Plans (R&W)
2. Configure⚙️ Settings → Azure DevOps → Enter Org URL + PAT
3. TestClick "Test Connection" — validates PAT format
4. PushGenerate TCs → 🔷 ADO → Select plan → Push

Jira Zephyr Export

StepAction
1. Get Tokenid.atlassian.com → Security → API tokens
2. Configure⚙️ Settings → Jira → Token + email + domain
3. GenerateGenerate test cases normally
4. ExportMore ▾ → Jira Zephyr → CSV downloads
5. ImportJira → Zephyr → Test Cases → Import
07 — Core Features

Generation & Editing Features

🎯 6 Output Types

E2E Scenarios, Smoke Tests, Field Validation, Integration Tests, Negative Tests, and Full Artifact (all combined).

✏️ Inline Edit Mode

Click any cell in the test case table to edit directly. Changes reflect in all exports instantly.

🔄 Iterative Refinement

Hover any test case and click regenerate. Add context to refine just that one TC without regenerating the whole suite.

🏢 Domain Intelligence

Select Insurance, Banking, HR, ERP, Retail or Healthcare for domain-aware TCs with business risk tagging.

📊 Quality Scores

Each test case gets an AI quality score (Good 95%, Fair 75%) with color-coded progress bars.

💬 Conversation History

Each session maintains context. Build on prior test suites without starting over.

🎯 Smart Detect

Auto-detects platform from pasted requirement text. Supports D365, Salesforce, SAP, ServiceNow, and more.

📋 100+ Templates

Pre-built templates for D365, Salesforce, Guidewire, ServiceNow, and more. Click to load instantly.
